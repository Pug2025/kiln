# Sound sources

Every file in this folder, where it came from, and its licence. Downloaded 2026-10-21.
All other game sounds (bricks, paddle, perfect hit, embers, drops, the fire roar, the level-clear
blast …) are synthesised in code (`src/audio/sfx.js`) and have no file.

Processing: decoded from the MP3, encoded with macOS `afconvert` to AAC-LC in .m4a, 44.1 kHz
stereo, 96 kbps.
